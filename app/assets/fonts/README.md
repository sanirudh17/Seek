# Figtree

Unmodified variable upright font, weights 300 to 900. UI uses regular (400), medium (500) and semibold (600); document and code fonts remain separate.

Source: https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/figtree

License: SIL Open Font License 1.1, included as OFL.txt. No system font installation or runtime download.
