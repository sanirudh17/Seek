# Item 1.1 — update ZIP compatibility and archive validation

Implemented on the revamp branch; version remains 1.0.2. No release or upload.

Extraction normalizes backslashes before checking the exact versioned top folder and fixed flat file allowlist. Traversal, absolute/drive/UNC paths, alternate streams, nested/unexpected files, aliases/duplicates and symlinks remain rejected. Folder errors now identify the expected prefix and a bounded representation of the actual entry.

The package writer now creates each entry with an explicit forward-slash name, fixed timestamp and sorted file order. A finished-archive guard rejects backslashes, incorrect top folders, unexpected/duplicate entries and incomplete payloads. The release build invokes this guard before checksumming or creating the installer. Existing 1.0.2 clients therefore receive slash-only names in any future package built with this script.

- The explicit published-ZIP extraction check executed once and passed (no payload executed).
- Six PowerShell fixture checks passed, including deterministic byte equality and malformed finished ZIP rejection.
