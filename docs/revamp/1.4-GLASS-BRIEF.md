# Glass refinement - item 1.4 (in progress)

Native Operate surface. Preserve a dark neutral workspace with visible live desktop acrylic. Stable material takes priority over eliminating mild Windows backdrop resampling during native maximize/minimize animation. Do not simulate glass with a desktop capture, remove all native animation, or switch material during each resize.

The neutral shell uses zero lightness. New profiles use a 72% black tint, matching the current Glint dark workspace surface. The window opacity slider now spans its full 0-100% range; user values are preserved. Sidebar tint follows a cubic response so the lower half is gentle. Main-pane glass adds no second scrim; Settings adds a 12% scrim and reflects window opacity live. Light mode, disabled transparency and high contrast remain opaque. Optional bounded local PNG backgrounds are display-only.

Native material ownership belongs to the GPUI Windows backend. Prefer system acrylic, extend the compositor frame through the full client area, and retain that material across native window states. Skip redundant material requests. Keep the visible material active independently of keyboard focus, suppress GDI erasure, and present after renderer resize. Windows retains control of native maximize/minimize animations.

Reference reading: Monodrive separates shell/sidebar tint from its main pane; Monocode uses native window controls rather than a custom maximize animation. Zeron uses native acrylic, without a special maximize animation. Glint material.rs supplies the full-client DWM contract and material.css uses a 72% black dark canvas. Onyx also uses native acrylic with separate dark surfaces. No GPUI upgrades or whole-file reference copies.

Latest evidence: debug build and strict Clippy passed; the combined app suite passed 80 tests (5 ignored). Three native maximize/restore/minimize/reopen cycles retained material type 3 across 13 states and exited normally. The full-client extension returned success. A later foreground capture of the maximized Settings popup showed the dark tinted backdrop; native readback confirmed material=3 and immersive-dark=1, with review settings opacity=60%, lightness=0 and sidebar=30%. Only the owned review profile had its earlier experimental 9% gray lightness reset to zero; user opacity values were retained. This checks the settled appearance, not every animation frame. The earlier quiet CPU sample included mouse/focus activity and is invalid as a zero-idle measurement. Startup, controlled idle, high contrast, transparency-off and complete background-picker acceptance remain unverified; item 1.4 is not complete.
