# Results frame and tab identity - item 1.7 follow-up

The table's keyboard focus indicator was painting around the entire results frame after Ctrl+I. Add a default-on DataTable focus_indicator option and opt out only for Seek's two result-table render paths (cached and accessibility). Keyboard focus, selection and row navigation remain active; the information-panel divider remains. Other component consumers retain the default indicator.

Tab identity had two mismatched sources: active labels used the live scope but glyphs used the saved tab scope, and the closing ghost always used Folder. Live glyphs now use live scope; inactive ones use saved scope; closing ghosts capture their own folder/search identity before removal. The virtual All locations context consistently uses Search, including during closing. Real folder tabs retain Folder.
