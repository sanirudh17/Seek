# Information panel motion - item 1.7 follow-up

Toolbar Info and Ctrl+I now share one toggle path. The panel slides from the right and fades over 160ms with cubic ease-out. Its width is reserved once on opening, retained during closing and released after the finite exit. Panel width is never animated per frame. Current progress is retained for interrupted reversals, close tasks are cancelled when toggled again, and generation checks prevent a stale close from hiding a reopened panel. Disabling Windows animation applies the final state immediately. There is no idle animation timer.

Ctrl+I routes before normal list/input focus guards, while Settings/edit/dialog/Quick Look routing remains respected. Preview data is retained through the close animation and released only after removal.

Combined debug build, 81 app tests (4 ignored), strict all-target/all-feature Clippy and whitespace checks passed. No app launch for this feedback pass. Visual smoothness, interrupted toggles, animation-off, high contrast and idle CPU remain unverified. This does not complete the full 1.7 motion list.
