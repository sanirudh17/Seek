# Selection inspector - item 2.2

Preserve the approved panel, Figtree, Hugeicons, dark glass and finite panel motion. Selection identity, Details, Dates and Storage remain compact; multiple selection replaces the single-file preview with counts, selected kinds and totals. Folder totals include descendants and collapse overlapping selected paths. Incomplete results use At least and name skipped, unreadable and unavailable allocation counts. Cancel and Recalculate are explicit actions.

Metadata waits for a 120 ms selection rest, then uses the existing details worker. Totals use a separate background task with a per-request cancellation flag and monotonically increasing revision; clearing/changing selection or hiding the panel cancels the old work. Data publishes as one summary update, rejecting stale results including an A/B/A selection. No periodic polling or UI-thread filesystem traversal is added. Parent directory guards are held through depth-first enumeration to prevent deletion/reparse replacement during child traversal; busy directories are reported incomplete. Reparse points and unavailable cloud items are skipped rather than hydrated. Enumeration memory follows depth, not total descendants.

Storage now uses read-only Windows owner/volume metadata. Failure to read ownership does not hide the volume. API references: [GetSecurityInfo](https://learn.microsoft.com/windows/win32/api/aclapi/nf-aclapi-getsecurityinfo), [GetVolumeInformationByHandleW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getvolumeinformationbyhandlew).

Open, Reveal, Copy path and Share actions reuse the existing browsing/file-action routes. Copy path/name/quoted path covers the displayed selection in order. Share uses the per-window Windows Share sheet and a deferred background storage-item resolver; handlers are revoked on replacement/drop. It opens the native sheet and does not choose a recipient or send files automatically. API reference: [desktop Windows Share integration](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/integrate-sharesheet-send).

Validation: debug build, 91 app tests (4 ignored), strict all-target/all-feature Clippy and whitespace checks pass. The owned junction-cycle and owner/volume tests passed on this Windows host. GUI acceptance remains pending. Native tests cover read-only owner/volume lookup, missing metadata, nested/overlapping totals, cancellation, skipped attribute classes, and an owned junction cycle when the host permits creation. Mutation/accessibility/idle and actual Share-sheet behavior remain live acceptance gates. New Folder with Selection remains dependent on safe journaled operations in item 2.5.
