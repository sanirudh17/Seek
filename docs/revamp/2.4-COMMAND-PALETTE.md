# 2.4 - Native Jump and command palette

Ctrl+K and the sidebar Jump button open a bounded native Command overlay. It filters favorite/root locations, eight Settings pages, List/Icons/Gallery, new tab, inspector and existing file actions. Disabled actions remain unavailable when selection/location context is absent. Execution reuses existing routes; no new mutation engine is introduced. Selection and scope are rechecked before executing a file command, avoiding a different target after an index refresh.

Escape or Ctrl+K closes immediately; outside click closes. Focus returns before command execution or cancellation. Tab stays within the palette query. Quick Look, rename, permanent-delete confirmation and active native dialogs prevent opening; file/tab actions are guarded while it is open. Confirm uses the component's original item coordinate, which remains stable under filtering. Palette rows now expose explicit accessibility labels.

Routine app launches are deferred to larger review checkpoints, each with a consolidated feature and shortcut checklist, per user direction. The approved Figtree/dark surface remains; palette uses a compact search/list/footer and the existing popup token. Long root paths remain filterable, with Windows extended prefix omitted from the label. No new timer or idle polling.

Validation: all-target/all-feature strict Clippy, full 104-test app suite and native debug+benchmarks build recorded in .references/command-palette-*.log. A fresh owned profile launched, Ctrl+K opened the visible native palette, and the screenshot was inspected. Follow-up native inspection confirmed filtering to the disabled inspector action, readable accessibility row names and the restored rounded-rectangle settings choices. User-driven navigation changed the view during earlier automation; full filtered Enter routing, focus-cycle, screen reader and idle acceptance remain pending. No claim that the whole revamp or the operation journal is complete.

## Follow-up from user review

Use existing 8 px rounded rectangles for default-view choices instead of pills; their text has an explicit centered line box and no positional offset for Figtree. Keep icons out of those choices. The final Jump launcher is a quiet keyboard-marked button at the sidebar bottom, following user feedback that a search-like button above Favorites competes with global file search. Query field is 40 px high, with an explicit 13 px size shared by query, rows and help text, and the shorter placeholder Search commands. Inspector requires an actual selection, not merely a keyboard caret; Quick Look requires a selected file, rename requires one selected item, and destination actions require a scope or selected folder. Selection/scope snapshots are captured at opening and checked again before file/inspector execution. No new destructive actions are added.

References inspected read-only: Downloads/seek-reference-images/05-monodrive-sidebar-and-inspector-reference.png, 09-tilde-feature-tour-contact-sheet.png and 10-tilde-markdown-live-editing-1.png. Impeccable Operate/craft-floor and Taste app-screen refinement rules preserve approved Figtree, Hugeicons, dark glass and native GPUI. No replacement web design or dependency upgrade.

Final typography pass after user feedback: query, command rows and footer use an explicit 13 px size, with Search commands as the short placeholder. The search input uses a 40 px min/max layout height instead of Input::h, whose inherent overload only affects multiline inputs. The same sizing correction makes text-reader Find actually 36 px tall without enlarging its font. Default-view labels have no manual positional shift. This last pass was built/tested without another app launch, as requested; it is folded into the next larger review checkpoint. Evidence: .references/jump-refinement-{clippy,tests,build}.log.

## Phase-two finish

The palette now groups actions under Locations, Searches, Recent files, Saved commands, Views and tabs, Files, Operations and Settings. Every row includes its group name and aliases in search keywords; empty headings disappear during filtering. Confirmation resolves both original section and row, avoiding the wrong action when a later group becomes the first visible match. A regression covers later-group routing, disabled rows and out-of-range coordinates. Contextual/result menus link to Jump after menu dismissal, so popup focus restoration cannot steal focus from its query. Eleven settings pages, saved-query management and explicitly run programs are exposed. Context menus retain everyday item actions and result menus retain modes/history plus conditionally available recovery/search actions.

The owned console program was verified in the native result sheet with nonempty output, exit zero and Escape dismissal before the final grouping change. The user then explicitly requested no further app launch; grouped final UI and final idle acceptance are recorded as not rerun rather than inferred from the build.
