# 2.5 - Operations and recovery shape

Operate mode. Keep existing ordinary-user Shell STA, Windows dialogs and progress. Correctness first: crash-safe operation journal, explicit per-item outcomes, cancellable progress, conflicts without silent overwrite, undo/redo and recycle Put Back. Native operations must supply actual post-operation destinations/identities; never infer a successful action from a UI request. Persist intent before mutation, flush outcome after each completed item, distinguish pending/partial/failed/undone, and reconcile interrupted records conservatively. Keep recovery scoped to owned profile storage; no elevated deletion, following reparse points or destructive startup retry. Undo refuses changed identities/content and never overwrites a collision. Recycle uses Shell item identity rather than guessing $Recycle.Bin names. Batch rename and New folder with selection depend on this foundation. Build owned-fixture tests for collisions, failure/cancel/partial completion, external changes and restart reconciliation before exposing destructive controls. Preserve explicit existing permanent-delete confirmation. Broad mutation work is not implied verified by palette routing.

## Initial code audit

Current IFileOperation worker already runs on a dedicated STA and forwards Shell progress/dialogs. It currently requests the Shell undo record but does not expose an app-owned undo/redo journal. Progress callbacks for rename, move, copy and new item currently discard HRESULT/new-item identity; these must supply durable per-item outcomes before any inverse operation can be trustworthy. Delete callbacks currently update removed rows only after success and confirmed absence; preserve that distinction. Clipboard copy/cut is not a completed file mutation and must not create an undo entry. Paste must resolve actual clipboard paths/cut intent before journaling. Existing permanent-delete confirmation remains separate and irreversible. Keep this phase marked pending until its durable recovery and fault tests are implemented.
