# Review feedback follow-up

This pass keeps the approved reader, PDF, Word, Excel, palette and tab presentation. Work and fixtures remain in the isolated worktree; no release or version change.

## Changes

- Rename/New folder and History use opaque theme-aware surfaces with distinct borders. A failed rename stays open with its error beside the input; the original file remains selected. Pending operations cannot be submitted repeatedly. Exact no-op renames do not create history or invalidate undo.
- Collision failures explain that the destination exists and the original was not renamed. Leading spaces remain valid Windows filenames, with an explicit hint. The review's apparent duplicate was ` 03 Edit conflict.txt`, distinct from `03 Edit conflict.txt`; the exact collision was rejected.
- Both GPUI Escape action types use one route through History, palette, dialogs, Find and Quick Look. Closing Find restores editor focus before removing its input. Dirty edits retain the existing save/discard/keep-editing choice.
- Image panning uses measured content bounds and explicit Shift+arrow actions. Clean previews yield to Ctrl+Tab/Ctrl+Shift+Tab; dirty/saving text keeps its save safeguards. Resolving a dirty prompt does not automatically replay a tab switch.
- The first Markdown checkbox save with backup retention has an exact-byte regression test. Saved status indicates when a backup is retained. The earlier review profile already contained backups; its initial observation alone does not establish a failed save.
- Find uses explicit height/font constraints because custom component Size values fell through to the 24 px input height. After user review of the larger field, the final field is 30 logical px with reduced outer padding and an explicitly sized 18 px Match case icon in a 28 px control.

## Native glass rollback

The experimental minimize-transition suppression was rejected and removed. The previous visible/non-iconic material guard is restored from b6691c2. Windows owns normal minimize, maximize and restore animations. No active-window-appearance override or accent-material experiment is included. The final native window.rs is unchanged from that earlier implementation. Existing sidebar and inspector animations remain intact.

A focused launch visibly reflected the blue backdrop; an inactive observation was flat gray. A temporary native active-material probe was tested only on an owned test window and was not incorporated. User then reported white app-switch flashes and requested rollback. The subsequent user report said the presentation looked good and requested only the Find adjustment. This is user acceptance of the settled presentation; it does not establish frame-by-frame absence of transient flashes. No further speculative compositor changes are part of this pass.
