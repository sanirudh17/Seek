# Search continuation shape

Preserve the existing engine and search field. Existing parsed filter tokens remain the filter chips; improve their discoverability through explicit result-mode/type menus rather than adding a competing input. Persist bounded saved/recent searches with their scope and filename/content mode. Saved queries live in the sidebar and command palette; users can save the current query and remove saved entries explicitly. Recalling a content query must restore content mode rather than reinterpret it as a filename query.

Content matches retain up to five matching lines, original line numbers and visible excerpt truncation. Keep compact list rows and expose the complete five-line evidence in the inspector. Do not imply that bounded excerpts are complete documents or that quick catalog hits have already completed a fresh scan. Test Unicode folding, long lines, match limits, persistence and preservation of unrelated settings. Search engine regression tests remain mandatory.
