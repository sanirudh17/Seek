# Interaction continuation shape

Retain the approved sidebar, one search field, native image/provider thumbnails and OLE drag behavior. Add discoverable Alt+number favorite shortcuts without changing existing Ctrl+number view shortcuts. Show recent successful opens from the existing opened-date evidence. Read drive capacity and recent files on a worker in response to location/open changes, with no idle polling and no network-drive probe on the UI thread.

Internal folder drop targets get restrained valid-target feedback. Reject self/descendant/already-contained drops before queueing. Hover expansion is delayed, read-only and cancelled on leave, Escape or drag completion; it never performs the move. Escape cancels a live drag before acting on the browser selection. External drops retain Shell Copy-only behavior and source preservation. Thumbnail/provider work remains bounded to visible and active-preview keys; final native acceptance covers real image sizes and cancellation.
