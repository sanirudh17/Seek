# Saved commands shape

Use a dedicated Saved commands settings page with a name, full executable path, one argument per line, optional working directory and explicit selection requirement. Explain `{file}`, `{files}`, `{name}` and `{folder}` at the fields where they are used. No combined shell command string or implicit interpreter. A saved command runs only through its explicit context-menu or command-palette action; saving, searching or selecting never executes it.

Validate configuration and argument expansion, preserve argument boundaries and lossless standalone path arguments, enforce selection requirements at invocation and guard stale palette selection. Report launch acceptance separately from process completion. Test spaces, Unicode, shell metacharacters as literal argv, multiple selections, unknown placeholders, missing context, persistence and a harmless owned-file native executable invocation.
